# Product photos

Drop a real photo of each pre-owned unit here to replace the SVG render on its card.

- File name must match the product `id` in `lib/products.ts`, e.g. `iphone-15-pro.jpg`.
- Then set `image: "/products/iphone-15-pro.jpg"` on that product in `lib/products.ts`.
- Square-ish PNG/JPG with a transparent or dark background looks best.

Until a photo is added, the card shows an original SVG iPhone render (color-matched to the selected finish), so the store always looks complete.
